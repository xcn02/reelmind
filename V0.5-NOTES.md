# ReelMind V0.5 — lot hybride expérimental

Ce ZIP reprend la V0.4 et ajoute :

- Réception du partage via une activité légère dédiée (retour rapide à Instagram).
- Paramètres : moteur local, Render facultatif, priorité, transcription, analyse d’images, catégories, stockage.
- yt-dlp + FFmpeg Android, bouton de mise à jour du moteur.
- Métadonnées et audio via yt-dlp; transcription via Groq Whisper Turbo (clé Groq requise).
- Mini-backend FastAPI + yt-dlp + gallery-dl pour carrousels en secours.
- Analyse de carrousels/images via Gemini; ajout manuel d'images via sélecteur Android.
- Colonnes Room V5 + migration explicite V4→V5 et versionCode 5.
- Miniatures réseau avec Coil dans les cartes.

**Limites et précautions importantes :**
- Compilation Android **non validée ici** : environnement sans Gradle/Android SDK. Lancer GitHub Actions, inspecter les erreurs de compilation éventuelles avant installation.
- Le backend Render n'est **pas déployé**. L'URL reste vide jusqu'à configuration dans les paramètres. Le service FastAPI d'exemple est sans authentification : ne pas le rendre public tel quel, ajouter un contrôle d'accès et des limites de requêtes.
- Les extracteurs Instagram sont incertains; le carrousel dépend du support public de gallery-dl.
- L'interface de lecture vidéo intégrée, un moteur de recherche FTS avancé et un vrai lecteur hors-ligne ne sont **pas inclus** dans ce lot.
- Les vidéos ne sont pas archivées ; seuls les médias temporaires nécessaires au traitement sont téléchargés.
- Les clés API sont conservées dans les préférences locales (comme en V0.4), sans coffre-fort chiffré dédié. Ne pas distribuer cette APK telle quelle avec tes clés préconfigurées.
- Bibliothèque yt-dlp sous licence GPL-3.0 : vérifier les implications de distribution du code et de l'APK.

**Installation et contrôle**
1. Décompresser à la racine du dépôt GitHub existant, remplacer les fichiers et pousser sur main.
2. La GitHub Action conserve le workflow signé avec les mêmes secrets qu'en V0.4.
3. Vérifier que l'APK release compilée garde le package `fr.reelmind.app`, la signature identique et versionCode 5.
4. Ouvrir Réglages → saisir URL HTTPS Render si utilisé + clés Gemini/Groq.
5. Tester d'abord un Reel public, puis un carrousel public, puis un import de capture.
6. Ne pas désinstaller la V0.4 : une désinstallation efface les données locales.
