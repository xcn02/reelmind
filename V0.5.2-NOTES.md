# ReelMind Android v0.5.2 — modifications (source)

Basé sur `ReelMind-v0.5.1-interface-bleue-arm64.zip`. App ID inchangé (`fr.reelmind.app`), `versionCode` 7, ARM64 uniquement. Base Room conservée en version 5, sans suppression de données.

- Titre des nouvelles fiches basé sur la première phrase de la légende, sans IA. Les fiches anciennes ne sont pas recalculées.
- Ne pas traiter le titre générique retourné par yt-dlp comme un titre Instagram authentique.
- WorkManager : aucune nouvelle tentative automatique en cas d'échec de traitement. Statut et message d'erreur conservés.
- Catégories : véritable gestionnaire (ajout, renommage, icône, couleur, suppression), données stockées dans les préférences ; renommage/suppression réaffecte les catégories des fiches sans les supprimer.
- Fiches : Télécharger (yt-dlp local, sans IA), Partager l'URL, Instagram ; suppression en bas de fiche.
- Téléchargement : Android 10+ -> Téléchargements/ReelMind ; Android 8/9 -> dossier externe privé de l'application pour éviter la permission stockage globale.
- Auto-enregistrement du titre, de la catégorie, des notes et du texte source ; requêtes SQL partielles pour protéger les données de l'analyse asynchrone. Le résumé corrigé manuellement dispose de son propre bouton.
- Transcription et erreurs de traitement continuent d'être visibles dans le détail.

## Vérifications indispensables

Ce paquet contient le **code source**, pas un APK. L'environnement de préparation ne dispose pas d'une chaîne Android SDK/Gradle opérationnelle ; aucune compilation Android ni test sur appareil n'a été effectuée. Construire avec GitHub Actions et vérifier les erreurs éventuelles avant distribution.

À tester particulièrement : extraction yt-dlp d'une URL publique, téléchargement vidéo sur Android, transcription (si clé configurée), erreurs Gemini 429/503, reprise après fermeture, renommage/suppression des catégories, édition de notes pendant une analyse, installation par-dessus v0.5.1 avec la **même signature**.

Les modèles Gemini affichés dans les paramètres proviennent de la version de base et n'ont pas été validés contre la liste actuelle des modèles disponibles ; configurez un identifiant de modèle réellement autorisé par votre compte.
