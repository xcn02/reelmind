# ReelMind 0.5.1 — correctifs et ergonomie

## Changements

- Nouvel accueil inspiré d'une bibliothèque visuelle : recherche, miniatures récentes, catégories en grille, fiches et contenu à redécouvrir.
- Navigation Accueil / Recherche / Réglages.
- Paramètres intégralement défilables.
- Thèmes Clair / Sombre / Automatique (selon Android), enregistrés dans les préférences.
- Identité de couleur bleue, adaptée au logo ReelMind.
- Modèle de résumé Gemini par défaut `gemini-3.5-flash-lite`; correction automatique de l'ancien choix `gemini-2.5-flash` même dans les préférences existantes.
- Champs visibles : fournisseur, modèle, clés API Gemini/Groq/du fournisseur, paramètres locaux/Render.
- Choix de transcription audio Groq / Gemini / Désactivée ; modèle audio Gemini personnalisable.
- Modèle Gemini Vision paramétrable pour les images.
- Catégories par défaut, sélection de catégorie pour chaque fiche et création avec nom, emoji et couleur.
- Classement automatique avec instruction IA de choisir une catégorie parmi celles existantes, avec repli heuristique. Ne plus assigner un assemblage de hashtags comme catégorie.
- Fiche : résumé en premier, bloc Analyse, bouton Ajouter un média (Image/Audio/Vidéo), légende et transcription repliables, un seul champ Mes notes.
- Médias d'analyse importés traités dans le cache de l'application et supprimés après traitement ; aucune section permanente de pièces jointes.
- Android ABI arm64-v8a uniquement, même applicationId et même configuration de signature release.

## Limites actuelles

- **Aucune compilation Android** n'a été effectuée dans l'environnement de préparation (SDK Android/Gradle indisponibles). La validation de compilation revient à GitHub Actions.
- L'extraction Instagram dépend des limitations de la plateforme et peut échouer malgré yt-dlp et le backend.
- Un fichier vidéo importé manuellement est traité par Gemini (limite 12 Mio) : la conversion audio locale de vidéos arbitraires vers Groq n'est pas implémentée sans FFmpeg. Le traitement automatique yt-dlp peut récupérer directement une piste audio M4A/MP3 pour Groq.
- Les modèles Google disponibles dépendent des droits API de la clé. Les noms sont modifiables dans Réglages.
- Recherche actuelle purement textuelle ; les embeddings et la lecture vidéo embarquée ne sont pas inclus dans ce lot.
- Les clés API sont conservées dans SharedPreferences sans chiffrement applicatif supplémentaire.
- La création de catégories est opérationnelle ; la modification/suppression des catégories personnalisées reste à développer.
